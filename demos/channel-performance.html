Promotions out-earn placements

Promotion campaigns average a 3.9x return against 3.5x for sponsored placements, but placements drive 1.6x the order volume, so the mix question is reach versus efficiency, not either-or.

The weekend carries the week

Friday and Saturday return around 5x per dollar against roughly 3.5x midweek. Shifting the 2.0x late-night placement budget toward weekend windows is the clearest reallocation candidate.

Marketplace A converts a larger basket

Baskets on Marketplace A run about $4.50 higher than Marketplace B, so it is worth testing B's 4.6x weekend bundle promotion on A's audience.
