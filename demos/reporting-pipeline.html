What each stage does

Same four stages in every lane; that is what makes 25 funds maintainable

QueryRuns the domain's master query against the source system for all funds in scope: one parameterised query, not one per fund.
ExtractPulls the result set and maps it to the reporting schema: fund, period, line item, value, source reference.
ValidateApplies the rule set: completeness, period roll-forward, cross-domain ties, tolerance bands. Failures become exceptions, never silent overwrites.
LoadWrites validated values into the reporting workbook cells they belong to, with the source reference attached to every figure.

Fan out by domain, not by fund

Four lanes carry 25 funds because the fund is a parameter, not a branch. Adding fund 26 is a register row, not a new pipeline.

Validate before load, always

Every figure passes the rule set before it touches the workbook. Exceptions are routed to people with context attached, not overwritten and not ignored.

A human gate before publication

The chain prepares; a named reviewer approves. Automation removes the re-keying, not the accountability.
